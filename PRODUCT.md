# Product Brief — 90-Day Recomp Tracker

## Purpose
A mobile-first, offline-capable static Progressive Web App (PWA) for executing a 90-day body recomposition plan (Nov 24, 2026 – Feb 22, 2027) on the gym floor and at home with zero backend dependency.

## Primary User & Context
- **Scene:** Commercial gym floor with sweaty hands, one-handed phone use between 60–180s rest intervals, plus quick morning weigh-in and daily meal/habit check-ins.
- **Core Job:** Log sets (`weight × reps @ RIR`) in 1–2 taps without typing, run rest timers automatically, handle busy-gym swaps and supersets smoothly, hit 180–185g daily protein across 4 meals, and track 7-day rolling weight average and Big 3 progression.

## Surface Mode
**Operate** — task completion speed, scannability, thumb-zone reachability, and reliable state persistence take priority over decorative chrome.
